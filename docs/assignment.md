# 小组作业任务链

依据课程57页PBL课件整理；它是工作安排，不是已完成结果。

## 课件要求

| 页码 | 需要完成的工作 | 中间产物 |
|---|---|---|
| 1–13 | 读论文、拆PICOTS、明确时间零点和结局 | 数据需求说明书 |
| 14–24 | 查表结构、字典、单位、三级ID；取得原代码 | 变量映射表与来源版本 |
| 25–37 | 理解筛选、聚合、JOIN、NULL、去重、时间运算 | 可解释的查询片段 |
| 38–46 | 完成Q1–Q6，构建队列并计算阈值后结局 | 分段SQL与逐级人数 |
| 47–56 | 在pgAdmin运行、质控、解释差异、汇报 | SQL、1页结果说明、3分钟汇报 |

课件评分：队列正确性30、SQL可复现30、质控解释25、表达协作15。课件列有可选扩展与自测；教师最终作业要求及截止时间须另行确认。

## Q1–Q6

1. **Q1 数据在哪**：确认数据库、schema、表字段及字典。完成00_preflight和01_id_counts；分清subject_id（患者）、hadm_id（住院）、stay_id（ICU入住）。
2. **Q2 谁进入队列**：明确成人、非择期/当日手术、通气、气切、治疗目标等条件；先判定所有合格入住，再按每人首次合格入住去重。每一步保存汇总人数，不用论文人数反推筛选参数。
3. **Q3 什么时刻入组**：定义NRB/NIV/HFNC、FiO₂≥0.40及同时成立规则；核对原文前向填充窗口，区分严格同一记录时刻的课堂简化。记录FiO₂单位及流量估算使用情况。
4. **Q4 阈值及结局**：在未插管且仍被随访的人中，找首次动脉血P:F<80；以该时点为起点判定3小时内新开始有创通气，明确出ICU、死亡及120小时的截尾规则。
5. **Q5 汇总与分母**：分母为达到阈值的独立患者，分子为结局窗内有创通气者。无插管记录者也须保留；输出达标人数、插管人数和比例。
6. **Q6 基线与可信度**：补充年龄、性别、race、ICU类型、COPD/CHF等。核对ICD代码集合、缺失率、去重与时间顺序，再解释和论文的差异。

## 小组分工建议

| 角色 | 负责内容 |
|---|---|
| 队列负责人 | 纳入排除、每人首次合格入住、人数流程 |
| 变量负责人 | 字典、字段、单位、装置和ICD映射 |
| 时间轴负责人 | 入组、阈值、通气起点与截尾 |
| 质控/汇报负责人 | 重复、缺失、时间顺序、差异及展示 |

4–5人可轮换角色；每人至少能解释一个查询片段和一个质控结果。

## 验收

- 同组另一人从头执行SQL能得到相同汇总结果。
- 每层COUNT(*)与独立ID数均核对；不把JOIN产生的事件行数当人数。
- 阈值发生时仍在风险集；不使用已经插管后的P:F充当暴露。
- 三小时结局分母保留未插管者，并写明观察不足3小时的处理。
- 结果说明包含数据/代码版本、缺失和方法偏离，不以“数字接近19%”代替质控。
- GitHub提交仅含代码、文档和检查后的汇总，不含临床明细。

**范围与方法。** 真实MIMIC-IV 2.2，PostgreSQL 16.15；PF<80单阈值课堂适配。成人非择期/非当日手术，在ICU前6h至后24h寻找NRB/HFNC/NIV及FiO₂≥40%同记录时刻；排除入组时及其后30min内IMV、入组后120h内气切、明确CMO/DNI及无效随访，先判断合格再每人取首次合格入住。阈值须为入组后、插管前的首次有效动脉PF<80，最近8h装置仍合格；不要求此前先有PF≥80。随访至出ICU、已知院内死亡或入组120h最早者。

**人数流程。** 73,181次ICU → 成人非择期等62,757 → 指定装置5,200 → 同时FiO₂≥40% 3,309 → 排除已有IMV/气切等3,107 → 排除明确治疗限制2,751 → 首次合格入住2,569人 → 达阈值176人。前段按入住、末段按患者，不能混称。

**解释与局限。** 覆盖统计只要求ART.、时间窗、PF非空及FiO₂ 20%–100%，并非全部阈值质量检查。治疗限制使用ICU入住后144h内记录，可能含入组后信息并影响样本选择；未记录不等于明确Full code，单独DNR不排除。数据版本、同时配对、派生PF、排除与原文不同；未做17阈值、100套插补及回归，教师配套SQL和期刊补充仍缺。结果描述已观测的治疗行为，不能确定最佳插管阈值或治疗效果。

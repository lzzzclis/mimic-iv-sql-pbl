# 结果解释审查（2026-11-15）

## 可以报告的主结论

在本地MIMIC-IV 2.2按明确规则筛得的2,569名患者中，176人记录到插管前、指定氧疗状态下的动脉PF<80；其中41人在该记录后3小时内且随访截止前记录到有创机械通气，观察比例41/176=23.30%。这是单阈值、描述性的课堂适配。

首次记录到PF<80不等于生理上第一次降到80以下，也不要求此前先有PF≥80。入组时刻、阈值时刻和ICU入住时刻是三个不同的时间。

## 缺失：当前结果最大的外推限制

2,569人中，1,482人（57.69%）在入组后、插管前的随访窗内没有明确动脉血气；1,830人（71.23%）没有满足当前PF覆盖计数条件的记录。两者有重叠，不能相加。只有739人（28.77%）至少有一条满足该覆盖条件的记录。

这里的覆盖条件是：标本为ART.、处于指定时间窗、PF非空、FiO₂在20%–100%。该统计不额外检查PaO₂/PF正值，也不要求当时装置符合阈值条件。因此，覆盖统计是缺失提示，不能直接称为“完整通过全部阈值质量检查的739人”。实际阈值判定另加PaO₂/PF正值、PF<80、指定装置及时间先后条件。

未测到PF<80可能源于没有抽血、缺少FiO₂、采样时间、装置条件或确实未达到阈值，不能统一叫“PF正常”。不能用176/2569解释严重低氧的真实发生率，也不能把有PF记录的739人直接设成新的主分析分母。缺失很可能与病情和临床决策有关；本次没有检验缺失机制，也无法确定偏倚方向。

## 时间与结局

主结果使用≤3h；严格<3h也是41人，恰好3h为0人。176人中有2人尚未观察满3h且未见IMV便到达非IMV随访终点：转出ICU1人、入组120h截止1人。主结果保留两人，并报告短随访。因此23.30%是规定窗口内的观察比例，不是经删失校正的3小时累积发生风险。不能把转出后的治疗当成已完整追踪。

仅作分母敏感性演算，若删除上述2人，41/174=23.56%；这不是重新抽取的队列，也不纠正选择偏倚，不替代主结果。

## 治疗限制、FiO₂与装置

- 主分析扩展识别明确CMO/DNI，单独DNR保留；未见治疗状态记录的1,362人不等于明确Full code。记录截止ICU入住后144h，包含入组后的信息；它可能筛掉病程中后来改变治疗目标者，属于样本选择限制，不能把筛得队列称为“入组时已确定均无DNI”。气切排除也使用入组后120h内信息。
- 仅恢复作者治疗限制字段和值，结果为43/194=22.16%；与主分析差1.14个百分点。这只说明当前两种治疗限制口径下的结果，不能证明其他适配不影响结果。两种队列分别按患者选择首次合格入住，不能未经检查断言一组就是另一组的简单子集。
- 1,365人（53.13%）入组FiO₂依赖流量规则估计；公式只是近似，不能当实测。阈值PF来自派生bg中另行配对的FiO₂，与入组FiO₂来源不完全相同。
- 入组要求装置/FiO₂同记录时刻，阈值装置采用最近8h非空记录。严格同时点可能漏掉实际同时接受治疗但记录不同步者；8h沿用可能错误代表实时装置。未评估其误分类程度。

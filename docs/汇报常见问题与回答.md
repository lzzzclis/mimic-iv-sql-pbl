# 汇报常见问题与回答

本稿为本地AI辅助准备的答疑参考。回答对应当前真实结果；不是用户已完成口试或独立运行的记录。

**1．这份作业到底回答什么？**

在符合本次规则的患者中，首次记录到插管前PF<80后，有多少人在随后3小时内记录到有创机械通气。我们描述医疗行为，没有判断应不应该插管。

**2．23.30%怎么算？为什么不是除以2,569？**

41÷176×100%。题目限定“达到阈值之后”，所以分母是176名记录到符合条件PF<80的人。2,569是更早一步筛出的总队列。

**3．P或PF是什么？80是80%吗？**

PF=PaO₂/FiO₂。PaO₂用mmHg，FiO₂作为比例参与除法；数据库若存百分数，就用100×PaO₂/FiO₂%。80不是血氧饱和度80%，PF≥80也不等于正常。

**4．首次PF<80是否一定先有PF≥80？为什么不用LAG？**

不一定。当前定义只找第一条合格的低PF记录，筛选后按时间取最早即可。LAG适合“前一条≥80，当前<80”的跨越练习；那会换掉研究问题，还会漏掉第一条记录就低于80的人。

**5．为何要先筛入住，再按患者去重？**

同一患者可能住过多次ICU。先只留第一次ICU可能保留不合格的一次，漏掉后来合格的一次。本次先判断各次入住，再按ICU入住时间保留首次合格入住，所以最终每位患者计一次。

**6．怎样保证不是插管导致血气变低之后才算达标？**

阈值血气必须早于首次IMV，并在入组后、随访结束前；最近8h装置记录仍须是指定非有创氧疗。这样排除已记录插管同时及之后的血气，但不能保证记录时间毫无误差。

**7．为什么需要LEFT JOIN和COALESCE？**

LEFT JOIN保留没有匹配记录的人，右边缺失为NULL。判断结局时，用COALESCE把“没有记录到符合窗口的IMV”记为FALSE，保留在176人的分母。它不表示此人在整个病程都没插管，也不表示完全追踪了3小时。

**8．观察不足3小时怎么处理？**

有2人未观察满3h且没有窗口内IMV：1人出ICU，1人达到120h截止。主结果按原定规则保留并报告，因此称观察比例。删除两人仅作分母演算得到23.56%，不是删失校正，也不替代23.30%。

**9．1,830人没有PF覆盖，会影响结论吗？**

会限制外推。71.23%的人没有满足当前覆盖计数条件的PF记录，未观测到阈值不能解释成正常。谁抽血、何时抽血可能与病情有关；本次未做该缺失机制分析。此覆盖条件也不是全部阈值质量条件，具体见审查说明。

**10．你们有没有把静脉血气混进去？FiO₂是否都实测？**

阈值只接受bg中明确ART.的动脉血。入组FiO₂优先记录值，缺失时仅NRB按指定流量规则近似；1,365人依赖该规则。阈值PF使用bg已有配对，所以也存在配对时间和测量误差。

**11．DNR和DNI为什么要分开？**

DNR表示不做心肺复苏，不必然限制插管；DNI明确不插管。本次排除明确DNI/CMO，单独DNR保留。没有所查记录不等于明确Full code。

**12．治疗限制是否均在入组时已存在？**

不是。脚本读取至ICU入住后144h的记录，可能包含后来变更的目标；这是明确的样本选择限制。我们没有把它改称“纯基线排除”，也不能据此作因果推断。

**13．为什么另有22.16%？哪一个是主结果？**

23.30%是扩展明确治疗限制字段的主分析；22.16%是只恢复作者治疗限制字段和值的敏感性结果。其他本地适配仍保留，所以后者也不是完整作者复现。

**14．HFNC和NIV都是16.67%，能说明效果相同吗？**

不能。基线HFNC为8/48，NIV为1/6；装置并非随机分配，病情不同，小分组比例尤其不稳定。这里只展示计数，没有治疗效果比较。

**15．为什么同时有两种装置分层？**

PPT延伸要求按基线装置，论文Table4按达到阈值时装置。治疗过程中装置会变化，所以分别输出并保留各自分母。

**16．为什么与论文19%不同？是不是做错了？**

本地与原文数据版本、入组同时规则、治疗限制和FiO₂配对不同，且未执行完整插补和回归。应先核对定义与计算，不能只凭数字相近或不同判断正确。我们没有证据把差异归因于单一原因。

**17．质控全为零是否表示完全正确？**

它说明检查到的重复、时间顺序、范围等问题为零，复跑也一致。仍可能有共同的定义错误、记录误差或未检查到的偏倚；不等于临床有效性证明。

**18．怎样提速，是否改了研究问题？**

先缩小候选范围，复用一次治疗状态取数，使用已有派生表、临时索引和统计信息，只导出聚合。它们减少重复工作；单阈值、不做100套插补及回归则是研究范围的简化，两类变化分别说明。没有测量加速倍数。

**19．实际由谁完成哪些工作？**

用户确定课程目标、授权范围和简化方向，负责理解、审阅与最终提交；AI辅助核对材料、编写SQL、在本机执行与另会话复核、整理解释和文稿。不能把AI的技术复跑写成另一名真人完成，也不能把AI已经讲解写成用户已掌握。

# 变量映射与作者代码对照

数据版本MIMIC-IV 2.2；表字段已实际核对。所有临床中间表只在数据库会话内，不输出患者明细。

| 研究概念 | 本地表与字段 | 单位/连接/注意事项 |
|---|---|---|
| 患者/住院/ICU入住 | hosp.patients.subject_id / admissions.hadm_id / icu.icustays.stay_id | 三种编号不可互换；一人可多次住院/入住 |
| 年龄 | derived.icustay_detail.admission_age | 年；本次住院年龄，不直接把anchor_age当所有住院年龄 |
| 性别/种族 | patients.gender / admissions.race | race按本次hadm_id关联；未知/拒答单独计数 |
| ICU类型/时间 | icustays.first_careunit / intime / outtime | intime定义入组搜索窗；t0另行计算 |
| 入院年代 | patients.anchor_year_group | 脱敏前参照年代分组，并非该次ICU精确真实年份；不把2100年代平移日期当实际入院年 |
| 氧疗装置 | derived.oxygen_delivery，4个o2_delivery_device字段 | btrim去空格；同刻优先级气切>有创>NIV>HFNC>NRB |
| FiO2 | derived.ventilator_setting.fio2 | 已清洗为百分数；取20–100%，入组至少40%；查原始d_items.itemid223835 |
| NRB氧流量 | oxygen_delivery.o2_flow | L/min；实测缺失才估计21+3×流量%；不用于HFNC/NIV高流量；>25且≤100的NRB误录百分数按作者规则处理并列为估计 |
| PaO2/PF | derived.bg，specimen/po2/fio2/fio2_chartevents/pao2fio2ratio | 明确ART.；PaO2单位mmHg；PF=100×po2/FiO2百分数；血气FiO2优先，其次监护FiO2 |
| 监护FiO2配对 | bg源脚本stg3 | 同患者最近4h监护FiO2；它不是本次重新执行8h配对。研究时须说明派生口径 |
| 有创通气 | derived.ventilation，ventilation_status/starttime | InvasiveVent最早起点；不把NIV算成有创通气 |
| 气切 | ventilation.ventilation_status='Tracheostomy' | 与有创通气分开处理；不默认气切等于新插管 |
| 治疗限制 | icu.chartevents，d_items中Code Status字段 | 本地code_status派生表不存在；具体itemid与取值、原文/扩展口径见方法说明及实测汇总 |
| COPD/CHF | hosp.diagnoses_icd，hadm_id/icd_code/icd_version | 原作者Baseline_4代码集合，ICD9/10分开；无记录不代表临床排除疾病 |
| 死亡及住院结局 | admissions.deathtime/discharge_location | 院内已知时间；不把仅日期的院外dod强行变成ICU死亡时刻 |

`hosp/icu/derived`分别为`mimiciv_hosp/mimiciv_icu/mimiciv_derived`的省略写法；SQL使用全名。

## 作者四段SQL与PBL任务

| 作者文件（Zenodo v1.0.1） | 作用 | 课程对应与本地实现 |
|---|---|---|
| O2DeliveryFiO2Table_1.sql | 对齐装置/FiO2等 | Q1字典、Q3同时成立；本地用已有派生表 |
| PAHRC_OC_Eligibility_2.sql | 合格时刻、排除、每人去重 | Q2/Q3；原代码8hFiO2/装置、2hSpO2有限沿用，含SpO2≤100、+30min已有IMV检查 |
| PAHRC_OC_Timevarying_3.sql | 提取时变变量及终点 | Q4时间轴；它只提供基础事件，3h判定还在后续R，不是单靠此SQL就做完 |
| PAHRC_OC_Baseline_4.sql | 人口学、ICU和诊断 | Q5基线；p45也标作Q6，以上以概念对应 |

后续`CreateCohortR`清理时序并准备数据，`MultipleImputation`插补，`Outcomes/check_thresholds_obsonly.R`计算首次阈值与严格<3h结局，`Plots`出图。作者原始BigQuery脚本和私有项目表不能原样在本地F5执行。

至少三处迁移：BigQuery反引号三段表名改为schema.table；DATETIME_DIFF改为EXTRACT(EPOCH FROM(a-b))/60或/3600；LAST_VALUE IGNORE NULLS改为显式最近非空记录；数组OFFSET(0)改为PostgreSQL第1项或DISTINCT ON；COUNTIF改为COUNT(*) FILTER；字符串使用单引号。迁移语法不代表研究口径已自动相同。
